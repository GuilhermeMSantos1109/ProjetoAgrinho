# 🌱 Projeto Agrinho

Projeto desenvolvido para participação no concurso Agrinho.

## 📋 Sobre o projeto

Este projeto foi desenvolvido durante minha formação na área de tecnologia,
com o objetivo de aplicar conhecimentos de desenvolvimento web na criação
de uma solução relacionada ao tema proposto pelo concurso.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## 🎯 Objetivo

Aplicar na prática conceitos de desenvolvimento web, organização de código
e criação de interfaces.
